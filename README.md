# RaspiDashboard

A lightweight, real-time dashboard for Raspberry Pi, designed to monitor and display essential system information through a clean, dedicated screen.

## Overview

RaspiDashboard aims to turn a Raspberry Pi into a compact system-monitoring display, providing at-a-glance information about system status and performance.

The project is built on top of the **LVGL graphics library** and the **Waveshare ESP-IDF/LVGL example**, using it as a starting point for a custom dashboard interface.

## Goals

* **System monitoring:** Display essential system information in real time.
* **Landscape interface:** Make the most of a horizontal display layout.
* **Clean UI:** Present information in a clear, readable, and visually appealing way.
* **Lightweight design:** Keep the interface efficient and suitable for embedded hardware.
* **Customizable architecture:** Build a foundation that can be extended with additional metrics and features.

## Technology Stack

* Raspberry Pi
* LVGL (Light and Versatile Graphics Library)
* ESP-IDF / Waveshare example as the initial reference implementation
